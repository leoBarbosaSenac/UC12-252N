# Exercício Prático – Personalizando uma Página de Personagem com HTML e CSS

> **A internet está a nosso favor!** Pesquise, explore exemplos, descubra novos elementos HTML e propriedades CSS. Não tenha medo de testar e experimentar! A autonomia nos leva longe, e saber pesquisar é uma das habilidades mais importantes de quem desenvolve sistemas.

## 🎯 Objetivo

Utilizar os conhecimentos de HTML e CSS para personalizar a página desenvolvida no exercício de personagem, transformando-a em uma apresentação visualmente atraente, organizada e que represente bem o personagem escolhido.

## 📋 Enunciado

Utilize a página HTML desenvolvida no exercício de personagem e crie uma identidade visual para ela utilizando **CSS externo**.

A proposta é que você personalize a página da melhor forma que conseguir, explorando cores, fontes, imagens, espaçamentos, bordas e outros recursos que encontrar durante suas pesquisas.

Imagine que você está desenvolvendo uma página para apresentar seu personagem em um site. Como ela poderia ser organizada? Quais cores combinam com ele? Como destacar suas características, habilidades e história?

Use sua criatividade e transforme a página original em uma apresentação que você teria orgulho de mostrar!

## ✅ O que você deve fazer?

1. **Criar um arquivo CSS externo:** crie um arquivo chamado `style.css` e conecte-o ao HTML utilizando a tag `<link>` dentro do `<head>`.

2. **Personalizar as cores:** escolha cores para os textos, fundos e demais elementos que combinem com o personagem.

3. **Estilizar os textos:** personalize títulos, subtítulos e parágrafos utilizando propriedades como `color`, `font-size`, `font-family`, `text-align` e outras que considerar interessantes.

4. **Melhorar os espaçamentos:** utilize `margin`, `padding`, `width` e outras propriedades para organizar os elementos da página.

5. **Personalizar bordas:** experimente utilizar bordas, alterar suas cores e espessuras e arredondar os cantos dos elementos.

6. **Estilizar imagens e fundos:** personalize as imagens existentes e, se desejar, utilize imagens de fundo para enriquecer a apresentação.

7. **Utilizar seletores CSS:** explore seletores de elementos, classes e IDs para personalizar diferentes partes da página.

## 🚀 Vá além do básico!

Os itens anteriores são apenas um ponto de partida. Você pode pesquisar e experimentar outras possibilidades, como:

- Criar caixas para destacar informações importantes.
- Organizar as informações do personagem em diferentes seções.
- Personalizar listas de habilidades, características e equipamentos.
- Alterar a aparência dos links.
- Experimentar diferentes formas de posicionar os elementos.
- Descobrir novas propriedades CSS que ainda não foram apresentadas em aula.
- Pesquisar outros elementos HTML que possam enriquecer a estrutura da página.

Você não precisa utilizar todas essas sugestões. Escolha aquelas que fazem sentido para seu projeto e procure novas ideias por conta própria.

## 💡 Orientações

- Mantenha o HTML organizado e utilize o arquivo CSS externo para a estilização.
- Preserve as informações originais do personagem. O foco principal é a personalização visual.
- Pesquise propriedades e elementos que você ainda não conhece.
- Teste suas alterações no navegador e experimente diferentes combinações.
- Não tenha medo de errar: testar, observar o resultado e corrigir faz parte do aprendizado.

**O objetivo é transformar a página do seu personagem em algo único!** Não se limite ao que foi apresentado em aula. Explore, pesquise e descubra o que você consegue criar com HTML e CSS.
