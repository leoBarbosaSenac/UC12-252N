# Exercício: Recriando a Interface do Instagram

## Objetivo

Neste exercício, você deverá desenvolver uma página utilizando **HTML e CSS**, reproduzindo a interface do Instagram apresentada na imagem de referência.

O objetivo é praticar a estruturação de páginas com HTML semântico, trabalhar com diferentes propriedades de CSS e utilizar o **Display Flex (`display: flex`)** para organizar os elementos da interface.

## 1. Estrutura da interface

A página deverá conter os seguintes elementos:

### Menu lateral esquerdo

- Logotipo do Instagram na parte superior.
- Foto de perfil do usuário.
- Nome de usuário e nome de exibição.
- Informações de quantidade de publicações, seguidores e seguindo.
- Seção de sugestões de perfis, contendo foto, nome de usuário, descrição e opção de seguir.
- Opções de configurações e logout na parte inferior.

### Barra de navegação superior

- Campo de pesquisa.
- Ícones de navegação para Início, Explorar, Reels e outras funcionalidades.
- Ícones de mensagens e notificações.
- Botão para criar uma nova publicação.

### Área principal

- Seção de Stories, contendo imagens de perfil circulares e nomes de usuários.
- Feed de publicações, contendo pelo menos duas publicações.

Cada publicação deverá apresentar:

- Informações do perfil que realizou a publicação.
- Imagem principal da publicação.
- Nome de usuário e descrição.
- Área de comentários, contendo fotos de perfil, nomes e mensagens.
- Botões de curtir, comentar, compartilhar e salvar.
- Campo para adicionar um comentário.

## 2. Requisitos de desenvolvimento

Durante a construção da página, você deverá:

- Utilizar HTML semântico, empregando tags como `header`, `main`, `nav`, `section`, `article`, `aside` e `footer`, conforme a necessidade.
- Criar um arquivo CSS externo para toda a estilização.
- Utilizar `display: flex` para organizar os elementos da interface.
- Trabalhar com propriedades de CSS, como:
  - `background-color`
  - `color`
  - `font-family`
  - `font-size`
  - `width` e `height`
  - `margin` e `padding`
  - `border` e `border-radius`
  - `gap`
  - `justify-content`
  - `align-items`
  - `flex-direction`
  - `flex-wrap`
- Utilizar classes e IDs com nomes que façam sentido para identificar os elementos.
- Reproduzir os espaçamentos, alinhamentos, proporções e cores da interface de referência.

## 3. Utilização de placeholders

Não é necessário utilizar imagens reais neste exercício. Você deverá utilizar **placeholders** para representar as imagens de perfil, Stories e publicações.

Um *placeholder* é um elemento temporário utilizado para ocupar o espaço de um conteúdo que será inserido posteriormente.

Por exemplo, você pode utilizar um círculo com fundo cinza para representar uma foto de perfil ou um retângulo com uma cor de fundo para representar uma publicação.

Os placeholders deverão respeitar as proporções e os formatos das imagens originais, utilizando propriedades CSS como `width`, `height` e `border-radius`.
