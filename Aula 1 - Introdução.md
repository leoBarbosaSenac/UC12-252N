# Introdução ao Front-End

## O que é Front-End?

Front-End é a parte de um sistema, site ou aplicação com a qual o usuário interage diretamente. É tudo aquilo que aparece na tela e permite que o usuário utilize as funcionalidades do sistema.

Exemplos:
- Botões
- Menus
- Formulários
- Imagens
- Textos
- Animações
- Layouts

Quando você acessa sites como YouTube, Instagram ou Netflix, a interface que aparece na tela e as interações que você realiza fazem parte do Front-End.

---

# Diferença entre Front-End e Back-End

## Front-End

É responsável pela construção da interface e pela interação com o usuário.

Tecnologias principais:
- HTML
- CSS
- JavaScript

## Back-End

É responsável pelo processamento das informações, pelas regras de negócio e pela comunicação com bancos de dados e outros serviços.

Exemplos de funcionalidades:
- Autenticação de usuários
- Processamento de cadastros
- Armazenamento de informações
- Aplicação de regras do sistema
- Comunicação com bancos de dados

Tecnologias comuns:
- Node.js
- PHP
- Java
- Python
- Bancos de dados, como MySQL e PostgreSQL

**Importante:** Front-End e Back-End trabalham juntos para que um sistema funcione. Por exemplo, em um formulário de login, o Front-End apresenta os campos e envia as informações, enquanto o Back-End pode verificar se as credenciais são válidas.

# Tecnologias do Front-End

## HTML

O HTML (HyperText Markup Language) é uma linguagem de marcação responsável por estruturar o conteúdo de uma página web.

Com HTML, podemos definir:
- Títulos e parágrafos
- Imagens
- Links
- Listas
- Formulários
- Botões

Podemos comparar o HTML ao esqueleto de um site: ele define os elementos que compõem a página.

## CSS

O CSS (Cascading Style Sheets) é responsável pela apresentação visual dos elementos de uma página.

Com CSS, podemos:
- Alterar cores e fontes
- Definir tamanhos
- Organizar elementos na tela
- Criar layouts
- Adicionar animações
- Adaptar a aparência a diferentes tamanhos de tela

Podemos comparar o CSS às roupas e à aparência de uma pessoa: ele determina como os elementos serão apresentados visualmente.

## JavaScript

O JavaScript é uma linguagem de programação que permite adicionar comportamentos e interatividade às páginas web.

Com JavaScript, podemos:
- Responder a cliques
- Validar formulários
- Atualizar conteúdos sem recarregar toda a página
- Criar animações e interações
- Consumir APIs
- Manipular elementos da página

Podemos comparar o JavaScript ao conjunto de mecanismos que fazem as coisas acontecerem em um site.

# Como um site funciona?

De forma simplificada, o funcionamento de um site pode ser dividido em algumas etapas.

## Passo 1 — Acesso

O usuário digita um endereço ou clica em um link no navegador.

## Passo 2 — Comunicação

O navegador solicita os recursos necessários a um servidor, que pode enviar arquivos e outros dados.

## Passo 3 — Interpretação

O navegador interpreta o HTML, aplica os estilos do CSS e executa o JavaScript.

## Passo 4 — Exibição e interação

O site aparece na tela e o usuário pode interagir com seus elementos.

Esse processo pode se repetir durante a navegação, conforme o usuário realiza ações e novas informações precisam ser carregadas.

# O que é um navegador?

Um navegador é um programa utilizado para acessar e visualizar páginas e aplicações web.

Exemplos:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

O navegador interpreta HTML e CSS e executa JavaScript para apresentar as páginas e permitir a interação com elas.

---

# O que é responsividade?

Responsividade é a capacidade de uma interface se adaptar a diferentes tamanhos de tela e condições de visualização.

Um site responsivo pode reorganizar seus elementos para oferecer uma experiência adequada em:
- Celulares
- Tablets
- Notebooks
- Computadores de mesa
- Telas maiores, como televisões

Por exemplo, um menu que aparece horizontalmente em um computador pode ser reorganizado em um menu compacto em um celular.

A responsividade é importante porque as pessoas acessam sistemas web por diferentes dispositivos.

# UI e UX

Ao desenvolver uma interface, precisamos pensar tanto em sua apresentação visual quanto na experiência de quem vai utilizá-la. É nesse contexto que aparecem dois conceitos importantes: UI e UX.

## UI — User Interface (Interface do Usuário)

UI é a interface com a qual o usuário interage. No desenvolvimento Front-End, o termo costuma estar relacionado principalmente aos aspectos visuais e aos elementos interativos de um sistema.

Isso inclui:
- Cores e tipografia
- Botões e menus
- Ícones e imagens
- Organização dos elementos
- Espaçamentos e alinhamentos
- Estados visuais, como um botão selecionado ou desabilitado

**Exemplo:** imagine um aplicativo de música. O formato dos botões de reprodução, as cores da interface, os ícones e a disposição das playlists fazem parte das decisões de UI.

Uma boa UI ajuda o usuário a identificar os elementos, compreender sua função e interagir com o sistema.

## UX — User Experience (Experiência do Usuário)

UX é a experiência que uma pessoa tem ao utilizar um produto, sistema ou serviço. Envolve como ela percebe o uso, quais dificuldades encontra e se consegue realizar seus objetivos de maneira satisfatória.

Isso inclui:
- Facilidade de navegação
- Clareza das informações
- Quantidade de etapas para realizar uma tarefa
- Prevenção e recuperação de erros
- Acessibilidade
- Eficiência e satisfação durante o uso

**Exemplo:** imagine que você deseja comprar um ingresso pela internet. Se consegue encontrar o evento, escolher o lugar e concluir a compra sem confusão ou etapas desnecessárias, provavelmente teve uma boa experiência de UX.

Por outro lado, se o site apresenta informações confusas, exige muitos passos ou dificulta o pagamento, a experiência pode ser ruim, mesmo que a interface seja bonita.

## Qual é a diferença entre UI e UX?

Podemos resumir assim:

- **UI:** como a interface é apresentada e como seus elementos são organizados visualmente e para interação.
- **UX:** como é a experiência completa do usuário ao utilizar o produto para alcançar seus objetivos.

Os conceitos estão relacionados, mas não são a mesma coisa.

Uma interface pode ser visualmente bonita e, ainda assim, ser difícil de utilizar. Da mesma forma, um sistema funcional pode apresentar uma experiência ruim se suas informações forem confusas ou suas tarefas forem complicadas.

# Exemplo simples de estrutura Front-End

O código abaixo apresenta uma página HTML básica com um título e um botão.

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Site</title>
</head>
<body>

    <h1>Olá, mundo!</h1>
    <button>Clique aqui</button>

</body>
</html>
```

### O que está acontecendo nesse exemplo?

- `<!DOCTYPE html>` informa ao navegador que o documento utiliza HTML moderno.
- `<html lang="pt-BR">` define o idioma principal da página.
- `<head>` contém informações sobre o documento.
- `<meta charset="UTF-8">` permite a interpretação adequada de caracteres, incluindo acentos.
- `<meta name="viewport" ...>` ajuda a página a se adaptar à largura da tela do dispositivo.
- `<title>` define o título exibido na aba do navegador.
- `<body>` contém o conteúdo apresentado na página.
- `<h1>` cria um título principal.
- `<button>` cria um botão interativo.

Neste primeiro exemplo, o HTML define a estrutura da página. Ainda não adicionamos estilos personalizados com CSS nem comportamentos com JavaScript.
